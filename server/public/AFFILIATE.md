# AGI Engine 推广分润计划（Affiliate Program）

> 让开发者与推广者用真实、可追溯的方式，从推荐 AGI Engine 中获得回报。
> 本计划的所有数字与规则以本文为准；涉及现金结算的条款需创始人最终确认。

## 一句话

分享你的推荐链接 → 好友通过链接订阅并付款 → 你获得奖励。
当前默认运行**免费时长模式**（零现金风险）；**现金佣金模式**需申请与创始人确认后开启。

## 两种奖励模式

| 模式 | 奖励 | 状态 | 前提 |
|---|---|---|---|
| 免费时长（默认） | 每带来 1 个已付款且过退款窗口的用户，你与好友各 +1 个月 Pro | **运行中** | 自动，无需申请 |
| 现金佣金（可选） | 首年付款额的 **20%** | **需申请 + 创始人确认** | PayPal Payouts 权限 + 邀请制白名单 |

## 归因如何工作（真实机制）

1. 你在 Earn 页获得专属推荐码（形如 `AGI-A1B2C3`），由服务端签发。
2. 分享链接：`https://fnhiq23.github.io/agi-engine-v3/?ref=AGI-A1B2C3`
3. 好友点击后，`?ref=` 写入其浏览器（30 天归因窗口）。
4. 好友订阅时，推荐码编入 PayPal `custom_id`（格式 `v1|clientId|refCode`）。
5. Webhook 验签通过后，服务端记录归因与佣金；一次性 PayPal.Me 付款走认领表单兜底归因。
6. 你在 Earn 页可查：已邀请 / 已合格 / 待结算 / 已到账。

防作弊：推荐人不能用自己的推荐码给自己（自买不计）；未注册推荐码无效；重复交易去重。

## 现金结算的现实约束（诚实说明）

- PayPal Payouts API 需要单独申请权限，可能有地区限制与额度要求；**未开通前不承诺自动打款**。
- 降级方案：人工转账（需绑定收款邮箱）、免费时长、或礼品卡——具体以创始人确认的为准。
- 最低提现额、结算周期、税费代扣等细则，将在现金模式开启前另行公布并标注生效日期。
- 现金分润可能涉及税务申报义务，推广者需自行遵守所在地区法律。

## 如何参与

1. **普通推广者**：直接使用内建推荐链接，无需申请，自动进入免费时长模式。
2. **开发者 / 内容创作者**：贡献代码（见 `CONTRIBUTING.md`）或发布真实内容后，可申请成为认证联盟伙伴，解锁现金佣金（邀请制）。
3. 申请方式：发邮件到 **80306495@qq.com**，标题 `[AFFILIATE]`，附上你的推荐码、渠道与受众说明。

## API（供集成参考）

| 端点 | 用途 |
|---|---|
| `GET /api/referral/me?clientId=` | 获取本人推荐码与统计 |
| `GET /api/referral/resolve?code=` | 校验推荐码是否有效 |
| `POST /api/referral/bind-email` | 绑定收款邮箱（防自买） |
| `POST /api/event`（type=`referral_click`） | 上报推荐点击 |

- 不虚假宣传、不刷量、不批量注册、不冒充身份。
- 所有奖励基于**服务端已验证的真实付款**，未验签不计入。
- 本计划可调整；规则变更会在官方渠道公布，不追溯已结算奖励。
