FAQ

付款前，你可能想问

我的数据安全吗？你们能看到吗？
不能。记忆保存在你自己的浏览器本地，服务器只记录匿名埋点事件和付款认领状态，不存储、不读取你的内容。可启用 Privacy Vault 用 AES-256-GCM 加密，口令只有你知道。详见隐私政策。
为什么要收费？免费版不够吗？
免费版永久可用，核心功能都在。Pro 解锁无限加密记忆、高级搜索、全部成就与推荐返利。收费是为了让项目能持续维护，而不是靠广告或出卖数据。
为什么还要我自己配 API Key？
因为这是“数据主权”的一部分——模型调用由你直连模型商，不经过我们服务器，成本也由你直接控制。API Key 不会上传。模型费用与 Pro 费用分开。
能退款吗？
订阅可随时取消，已付费用原则上不退。若遇到重复扣款、付款后服务未开通等情形，可发邮件至 80306495@qq.com 申请，由创始人逐案确认（需创始人确认），不承诺具体结果。也可向 PayPal 申请买家保护。详见退款政策。

通过 PayPal 付款（年付 $100 / 月付 $15），也可用 PayPal.Me 转账。PayPal 处理支付，我们不接触你的银行卡信息。

换设备或清浏览器数据会怎样？
记忆存在本地，清理浏览器数据或换设备会导致本地数据丢失——请务必用导出功能自行备份。这是本地优先架构的诚实代价。

没有。我们不蹭任何概念。AGI Engine 就是本地运行的 AI 助手，用成熟加密标准保护数据。看到声称本项目有代币的信息，都不是官方。
