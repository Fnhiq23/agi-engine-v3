退款与取消政策 Refund & Cancellation Policy

生效日期：2026-11-27　　最后更新：2026-11-27

适用说明：本政策中凡标注「需创始人确认」的条款，均为需要创始人本人拍板后方可对外生效或执行的事项；未经确认，我们不承诺相关结果。最终退款决定由创始人/产品运营方依实际情况作出。

1. 订阅取消

  • 自动续费订阅可随时取消。你可通过 PayPal 账户中的"付款与收款 → 自动付款"管理并取消定期付款，或联系 80306495@qq.com 由我们协助处理。
  • 取消后，你的 Pro 权限持续至当前已付费周期结束；到期后自动降级，不会被再次扣款。
  • 取消订阅不等于退还已支付的费用。已付费用对应当前周期的服务，原则上不予退还，退款另按第 2 节处理。

2. 退款申请条件与流程

2.1 可提出退款申请的情形

如你认为存在以下情形，可提出退款申请：

  1. 重复扣款或金额错误：同一周期被重复收费，或实际扣款金额与展示价格不符；
  2. 付款后服务未开通：付款已到账并完成认领，但我们未能在合理时间内开通 Pro 权限，且经我们核实情况属实；
  3. 产品重大故障：因我们产品自身原因导致核心功能在较长时间内完全不可用，且你已及时反馈并给予合理修复机会；
  4. 其他合理情形：由创始人/产品运营方个案评估。
需创始人确认：具体是否退款、退款比例、退款时限以及上述情形的认定标准，均由创始人逐案确认。本政策不构成对任何具体退款结果的保证或承诺。

2.2 退款申请流程

  1. 发送邮件至 80306495@qq.com，标题注明"退款申请"，并附上：付款邮箱、PayPal 交易号、所购套餐、付款日期及申请理由；
  2. 我们在收到申请后进行核实，并可能要求补充信息；
  3. 核实后由创始人作出决定（需创始人确认），并通过邮件告知结果；
  4. 如获批准，退款将通过原 PayPal 支付渠道退回，到账时间以 PayPal 处理为准。
需创始人确认：退款审核时限（例如是否在若干工作日内答复）需在创始人确认后对外承诺；在确认前，我们仅承诺"在合理期限内处理"，不承诺固定时长。

2.3 不予退款的通常情形

以下情形通常不予退款（最终以创始人确认为准，需创始人确认）：

  • 已正常使用服务一段时间后，仅因个人偏好改变（"不想要了"）而提出的退款；
  • 因你自身 API Key 配置、网络环境、设备兼容性或第三方模型服务商原因导致的问题；
  • 因你违反《服务条款》而被终止权限；
  • 模型调用等由第三方收取的费用（我们从未收取该部分款项，无法退还）。

3. PayPal 买家保护说明

  • 付款由 PayPal 处理。PayPal 可能向其用户提供"买家保护"（Buyer Protection）等争议解决机制，适用的条件、范围与流程以 PayPal 官方政策为准。
  • 买家保护通常针对"未收到商品"或"商品与描述严重不符"等情形；数字产品/订阅类服务是否受保护、是否适用以及结果如何，由 PayPal 依其政策独立判断，我们不作出保证。
  • 若你在 PayPal 发起争议/索赔，请同时通过 80306495@qq.com 通知我们，以便我们与你沟通、提供信息并尽量减少误解。
  • 我们尊重 PayPal 的裁决；但 PayPal 的裁决与我们的退款决定是相互独立的两套机制。

4. 联系与生效

如有取消或退款相关问题，请联系 80306495@qq.com。本政策可能更新，更新后以本页面标注的日期为准。
