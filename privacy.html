隐私政策 Privacy Policy

生效日期：2026-11-27　　最后更新：2026-11-27

AGI Engine（以下简称"本产品"）是一款在用户浏览器本地运行的单文件 PWA 个人 AI 助手，支持 14 种语言。我们深知隐私是用户选择 AI 产品的基础，因此本政策以"数据尽量不离开你的设备"为设计原则。请在使用本产品前仔细阅读本政策。

1. 我们收集什么数据

我们只收集以下两类数据：

（1）匿名埋点事件（服务端）

为使产品团队了解功能使用情况，我们会记录有限的匿名事件，每条约包含：

  • clientId：浏览器本地生成的随机/匿名客户端标识，用于区分独立使用者，不包含你的姓名、邮箱等身份信息；
  • 事件类型：例如页面访问、功能点击、付费入口点击等事件名称；
  • 事件发生时间，以及用于渠道统计的匿名来源标记。

此类数据用于统计漏斗与转化，不包含你的对话内容、记忆内容或笔记内容。

（2）付款认领状态（服务端）

当你通过一次性付款链接付款并主动提交认领信息时，我们会记录用于核对到账与开通权限的最小必要信息，包括：你主动提交的邮箱地址、PayPal 交易号、所购套餐、clientId 以及认领的审核状态（待审核 / 已通过 / 已拒绝）。我们保存这些信息仅为完成付款核对与权限开通。

2. 我们不收集什么

为免歧义，我们在此明确声明：

  • 不存储你的记忆、笔记或对话内容。 这些内容保存在你自己浏览器的 localStorage 中，我们的服务器不接收、不存储、不读取它们。
  • 不收集你的 LLM API Key。 你的 API Key 由你在浏览器端填写，并用于直连你所选的模型服务商（OpenAI、Anthropic、OpenRouter、阶跃、本地 Ollama 等）。API Key 不上传至我们的服务器。
  • 不收集你的模型使用记录。 你与模型服务商之间的请求与响应，由该服务商按其隐私政策处理；我们无法访问。
  • 不收集精确地理位置、通讯录、相册、设备传感器数据。
  • 不出售、不出租、不共享你的个人数据给第三方用于广告或营销。

3. 数据存储在哪里

数据类型存储位置谁可访问
记忆、笔记、对话内容你自己浏览器的 localStorage仅你本人（及能使用该设备/浏览器的人）
加密后的记忆你自己浏览器的 localStorage仅持有你口令的人
匿名埋点事件我们的服务端数据库产品运营方（用于汇总统计）
付款认领状态我们的服务端数据库产品运营方（用于核对付款与开通权限）

本地加密说明：你可以选择在设置中启用 Privacy Vault，使用 Web Crypto API 对本机记忆进行加密。加密采用 AES-256-GCM 对称加密，密钥由 PBKDF2（210,000 次迭代 + 随机盐） 从你的口令派生。你的口令永不存储、永不上传。若口令丢失，加密数据将无法恢复——这是加密机制的正常特性，我们无法为你重置或找回。

浏览器本地存储的固有风险：清理浏览器数据、更换设备、使用隐私/无痕模式、或因浏览器策略导致站点数据被清除，都可能使本地记忆丢失。请注意使用产品内置的导出/备份功能自行备份。

4. Cookie 与本地存储说明

本产品不使用广告 Cookie、跨站跟踪 Cookie 或第三方追踪像素。

  • localStorage：用于在本地保存你的设置、记忆与笔记，属于本地存储而非 Cookie。
  • clientId：匿名客户端标识保存在本地，用于区分独立使用者与匿名统计。
  • 我们不接入第三方广告或分析 SDK；如未来接入，将提前更新本政策并说明。

5. 第三方服务

本产品的 AI 能力来自你自行选择的模型服务商。当你使用 AI 功能时，浏览器会按你的配置直连相应服务商（如 OpenAI、Anthropic、OpenRouter、阶跃，或你本机的 Ollama）。该等请求受对应服务商的隐私政策约束，我们不对第三方服务商的数据处理行为负责。此外，支付由 PayPal 处理，PayPal 按其隐私政策处理你的支付信息；我们不接触你的银行卡号等支付凭证。

6. 你的权利

在适用法律法规允许范围内，你可以：

  • 访问与导出：随时通过产品内置功能导出你的记忆与笔记；
  • 删除：通过产品内置功能删除单条记忆或清理本地数据；删除浏览器站点数据将清除本地存储内容（请谨慎操作并提前备份）；
  • 更正与撤回：对我们的服务端数据（埋点事件、付款认领信息）如有异议，可联系 80306495@qq.com 提出更正、删除或撤回请求；
  • 查询与投诉：可通过 80306495@qq.com 查询我们持有的与你相关的服务端数据，或提出投诉。

我们将在收到请求后于合理期限内处理，并可能要求你提供必要信息以核验身份。

7. 数据保留

  • 本地数据：由你自行管理，我们无法也不代为删除；
  • 匿名埋点事件：仅保留汇总统计所需的期限；
  • 付款认领状态：为履行付款核对、售后与支持义务保留，并在法律要求或业务必要时按规则处理。

8. 儿童隐私

本产品面向年满 16 周岁的个人使用。我们不会有意收集 16 周岁以下儿童的个人信息。若你发现此类情况，请联系 80306495@qq.com。

9. 政策更新

本政策可能随产品更新而修订。我们将在本页面更新"最后更新日期"。重大变更会通过产品内提示等方式通知。继续使用即表示你接受更新后的政策。
