## 3. 定价锚定论证：为什么 $100/年是合理的

**核心锚点：把年费放到竞品年费的对照系里看。**

- ChatGPT Plus / Claude Pro 约 $20/月 → **约 $240/年**（以官网为准）。
- AGI Engine Pro **$100/年**（折合 $8.33/月），不到上述主流订阅的**一半**；月付档 $15/月 也低于约 $20/月的行业锚点。
- 与 Notion AI（约 $96–120/年，且需另付基础套餐）相比，$100/年 落在同一区间，但我们提供的是**独立成品应用 + 数据主权**，而非依附于第三方平台的附加功能。

**我们便宜在哪：**
1. **一次性买断，不绑定按月无限扣费**——用户为"一整年的使用权"付费，而非被持续的月费订阅占用，心理账户上更可控。
2. **无云端托管成本转嫁**——数据本地运行、加密存储，用户不为平台的大规模基础设施买单。
3. **价格锚定在"省下的时间"上**——DIY 一套加密笔记 + AI 需要数小时至数天配置与持续维护；$100/年 是把这段时间成本折算成成品体验的合理定价。

**诚实的成本构成（必须向用户讲清楚）：**
- AGI Engine 用户需**自备 LLM API Key**，模型调用费用按各 API 服务商实际计费，由用户自行承担。
- 因此"总拥有成本 = $100/年（软件）+ 用户自付的 API 用量费"。这一点不回避——它正是"成本可控"的另一面：用户选择模型、设定用量上限，费用自己说了算，而非被平台打包定价。
- 对比：云端订阅的 $20/月 已包含模型调用，但用户无法自主选择模型，费用结构不透明。**我们是用透明度换取信任，而非用隐藏成本制造"便宜"的假象。**

## 5. 差异化风险（诚实自评）与化解

**风险 1：用户需自备 API Key**
- 劣势：相比 ChatGPT Plus 等"开箱即用"的订阅，用户需自行申请 API Key 并承担调用费，存在上手门槛。
- 化解：在 onboarding 中提供清晰的 Key 配置引导与主流服务商入口；用"成本透明、模型自选"把它转化为卖点，而非缺陷。

**风险 2：无移动端原生 App**
- 劣势：产品为单文件 PWA、浏览器本地运行，无 iOS/Android 原生应用，移动端体验受浏览器限制。
- 化解：强调 PWA 可添加到主屏幕、跨浏览器本地运行、数据本地加密；以"轻、无需安装、隐私更强"对冲原生 App 的缺失，诚实说明而非回避。

**风险 3：功能不如大厂全面**
- 劣势：在模型能力广度、插件生态、多模态等方面，无法与 ChatGPT/Claude 等大厂全面对标。
- 化解：不与大厂比"大而全"，而聚焦"小而精"的差异化定位——隐私、数据主权、成本可控、游戏化留存；把目标用户从"想要 everything"重新框定为"在意掌控权的人"。
