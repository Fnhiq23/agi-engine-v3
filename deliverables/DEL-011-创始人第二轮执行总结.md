# 创始人第二轮执行总结（2026-11-27）

## 一、战略决策：分层开源（创始人拍板）

用户问"整个代码要不要公开，还是公开一部分"。第一性原理判断：**护城河不在代码，在信任和流量**。

- 前端本就部署在 GitHub Pages，任何人打开即可看到全部源码——**正式开源零损失**，反而是隐私产品的信任资产（可审计=敢付费）+ 开发者传播入口。
- 后端密钥、邮箱授权码、增长作战情报公开会造成**资金安全风险与竞争优势丧失**——永不公开。

| 层级 | 内容 | 决策 |
|---|---|---|
| 完全公开 | index.html、4 个信任页、LICENSE/NOTICE/CONTRIBUTING/AFFILIATE、信任/SEO/KPI 文档 | MIT 开源 |
| 选择性公开 | server.js（建议脱敏审阅后）、DEL-001~004 增长情报 | 贡献者可见 |
| 永不公开 | server/.env、server/.mail.env、server/data/*.json | gitignore + 验证无泄露 |
