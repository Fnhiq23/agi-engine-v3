## 一、第一性原理拆解：为什么唯一瓶颈是"被发现"

### 1.1 收入公式与三变量现状

```
收入 R = 流量 T × 转化率 C × 客单价 A
```

| 变量 | 当前实测状态 | 证据来源 | 是否已被优化 |
|---|---|---|---|
| 流量 T | **0**（日活 = 0） | 创始人背景陈述 + 干净看板 | ❌ 完全没做 |
| 转化率 C | **无法测量**（无流量即无分母） | 逻辑推论 | ⚠️ 产品可信度已做（真加密/真支付） |
| 客单价 A | **已设定**：$100/年、$15/月 | `PRODUCTION_STATUS.md` | ✅ 已配置 |

代入当前值：

```
R = 0 × C × $100 = 0
```

### 1.2 零因子原则：约束在数学上只有一个

对乘法系统求偏导：

```
∂R/∂T = C × A   →   在当前 C、A 均 > 0 的前提下，∂R/∂T > 0
∂R/∂C = T × A   →   T = 0，所以 ∂R/∂C = 0
∂R/∂A = T × C   →   T = 0，所以 ∂R/∂A = 0
```

**结论（严格限定在"当前阶段"）：**

- 在流量为 0 时，调转化率、调定价，对收入的边际贡献**恒为 0**。
- 唯一能让 R 离开 0 的动作，是让 T > 0。
- 举例：假设某天 T = 1,000、C = 10%、A = $100，则 R = $10,000。这个数字不是预测，只是用来说明**流量是那个决定系统是否为零的开关**。

### 1.3 "不是产品"的论证边界（避免自我欺骗）

说"瓶颈不是产品"**不等于**"产品永远不需要改进"。准确表述是：

- 产品作为**技术交付物**已完成：能跑、能加密、能收款、能验证。这一部分不再是当前约束。
- 但产品作为**价值主张**仍有风险：BYO Key 意味着用户自己付 API 费，Pro 卖"无限聊天"站不住脚（`FOUNDER_PLAN.md` 已指出）。
- 因此：流量起来后，**转化率 C 会立刻变成新的绑定约束**。本作战地图的 Week 3 专门用真实对话去验证价值主张，就是为了提前处理这个下一约束。

> 一句话：**先让 0 变成 1，再让 1 变成 10。顺序反了，两手空空。**

## 二、用户是谁：3 个最可能付费的精准画像

> 说明：以下"付费理由"是**待验证的假设**，对应第 5 节的实验。不是已证明的事实。

### 画像 A：隐私洁癖的"第二大脑"使用者

| 维度 | 具体描述 |
|---|---|
| 典型人设 | 每天写日记/用 Obsidian、Logseq、备忘录记私人想法；已将笔记同步到云端但又隐隐不安的技术型白领 |
| 痛点 | "我把最私密的东西交给了一个我控制不了的服务器。" 他们已经为隐私付费（1Password ≈ $36/年、Obsidian Sync ≈ $48/年），但找不到一个"记忆真正加密、口令不上传"的 AI 层 |
| 在哪里出没 | `r/privacy`、`r/ObsidianMD`、`r/selfhosted`、V2EX、少数派、即刻"数字极简"话题 |
| 为什么愿付 $100/年 | **假设**：他们已有每年 $80+ 的隐私工具付费习惯；$100/年 ≈ $0.27/天，低于一次隐私泄露的心理成本。购买动机是"支持一个真把加密做对的项目"，而非买功能 |
| 触达话术锚点 | "AES-256-GCM，PBKDF2 21 万次，口令永不离开浏览器 —— 代码可直接审计" |
| 最大风险 | 他们也会问"BYO Key 那我到底买什么" → 必须诚实回答：目前买的是支持 + 早期访问权限，不是模型 |

### 画像 B：自托管 / 本地模型玩家

| 维度 | 具体描述 |
|---|---|
| 典型人设 | 家里跑 Ollama、LocalAI，玩过 AnythingLLM / PrivateGPT / MemPalace；喜欢折腾、反感 SaaS 锁定 |
| 痛点 | "我有本地模型了，但每次都要重新拼装记忆层；现成方案要么太重，要么把数据偷偷传走。" |
| 在哪里出没 | `r/LocalLLaMA`、`r/selfhosted`、Hacker News、GitHub star / issue 区 |
| 为什么愿付 $100/年 | **假设**：他们已为硬件和 API 花过钱，愿为"省去自己拼装记忆 + 加密层的时间"付费；但更可能先选 $15/月 或一次性赞助，年付需更强信任 |
| 触达话术锚点 | "单文件、纯前端、零后端依赖；你已有的 Ollama Key 直接能用" |
| 最大风险 | 这个人群 DIY 能力强、付费意愿弱 —— 他们更可能自己写一个。**他们是最会挑刺的评审，不是最好的客户** |

### 画像 C：反复交代背景的重度 AI 用户

| 维度 | 具体描述 |
|---|---|
| 典型人设 | 咨询师、研究者、独立开发者、内容创作者；每天和 AI 对话 5 次以上，跨会话重复说明身份/项目/偏好 |
| 痛点 | "每次开新对话都要把同样的话再说一遍，AI 永远不记得我是谁。" |
| 在哪里出没 | Twitter/X `#buildinpublic` 圈、Product Hunt、即刻、小红书 AI 工具话题、各类 AI 效率社群 |
| 为什么愿付 $100/年 | **假设**：时间成本论。每天省 10 分钟 ≈ 一年 60 小时，$100 折算时薪 < $2。前提是记忆真的跨会话可用且搜索可靠 |
| 触达话术锚点 | "Search your memories, export them, import them back — 你的背景不再每次重来" |
| 最大风险 | 对"本地加密"无感，只关心效率；且会用 ChatGPT Memory 免费版做对比 |

**优先级判断**：A（隐私）> C（效率）> B（极客）。B 适合做**口碑与代码审计**，不适合作为主要收入来源。

| 维度 | 权重 | 5 分 | 4 分 | 3 分 | 2 分及以下 |
|---|---|---|---|---|---|
| 触达成本 | 25% | $0 且准备 < 2h（现成文案） | $0 但需半天做素材 | $0 但需持续输出 | 需付费/广告预算 |

## 五、最小可行获客实验（7 天 / 成本 ≈ $0）

### 5.1 实验名称

**「5 个真实对话」付费意愿验证实验**

### 5.2 假设（可证伪）

> 假设：隐私优先的重度笔记用户，在真实试用本地加密记忆后，愿意为 Pro 支付 $100/年 或 $15/月。

### 5.3 实验设计

| 项目 | 内容 |
|---|---|
| 渠道 | **只选 1 个**：Reddit `r/privacy` 或 V2EX（按 Week 2 哪边反馈更好选） |
| 账号 | 创始人本人已有账号，**不注册新号、不买号** |
| 内容 | 用 `launch/` 中文文案改写为"求 5 位试用者 + 3 个问题调研"帖；明示 BYO Key、早期、无代币、无区块链 |
| 成本 | **$0**（无广告、无工具订阅、无外包） |
| 周期 | 7 天 |

### 5.4 7 天执行表

| 天 | 动作 |
|---|---|
| Day 1 | 定渠道、写帖；把 3 个问题固定下来，不中途改 |
| Day 2 | 用本人账号发帖；记录发帖时间与初始 UV（看板） |
| Day 3–4 | 对**每一位主动回复者** 1v1 真诚回复并邀请试用；问固定 3 问 |
| Day 5–6 | 整理回答；给每位完成试用者发**一次**真实付款链接（订阅或 PayPal.Me），观察是否真付 |
| Day 7 | 按下方决策规则复盘，写下结论 |

### 5.5 固定 3 问（不引导、不暗示）

1. 你现在用什么工具记私人笔记/想法？（**确认人群**，筛选画像 A）
2. 你过去一年为隐私类工具付过费吗？大概多少？（**测支付习惯**）
3. 如果它真的能做到本地加密记忆 + 搜索导出，你愿意付 $100/年、$15/月，还是只用免费版？（**测真实意愿**）

### 5.6 漏斗指标（目标值）

| 指标 | 计算方式 | 目标 |
|---|---|---|
| 主动回应率 | 主动回复人数 ÷ 帖子浏览数 | 记录即可，不设目标 |
| 试用转化 | 完成试用人数 ÷ 主动回复人数 | ≥ 50% |
| 付费意愿 | 明确说愿意付的人数 ÷ 完成试用人数 | ≥ 60% |
| **真实付款** | 看板/ PayPal 验证通过的付款人数 | **≥ 1（唯一硬指标）** |

### 5.7 预注册决策规则（防止事后找借口）

| 结果 | 结论 | 下一步 |
|---|---|---|
| ≥ 1 笔真实付款 | 信号成立 | 进入 Week 3–4，放大该渠道 |
| ≥ 5 人愿付但 0 付款 | 信任或价格问题 | 改测 $15/月 或 PayPal.Me 小额赞助，**不改产品** |
| < 2 人完成试用 | 渠道或价值主张错 | 换渠道重测，标题改"求反馈"而非"求试用" |
| 0 人回应 | 标题/分发问题 | 改标题、换社区重测一次 |

### 5.8 实验的诚实边界

- 样本量目标仅 5–10 人，**结果只能作为方向性信号，不能推算市场规模**。
- "愿意付"≠"真付款"；只有第 4 行硬指标算数。
- 无保证：完全可能 7 天后 0 付款。那也是有效结果——它告诉你下一个约束在哪。

## 六、合规红线（一票否决）

绝对不做，任何一条出现即停止该动作：

- ❌ 批量注册账号、买号、冒充他人身份
- ❌ 群发垃圾邮件 / 群发私信 / 刷赞刷票 / 买粉
- ❌ 冒充官方机构或伪造身份
- ❌ 编造数据、刷量、手工填假收入
- ❌ 宣传区块链 / 代币 / 链上收入 / 智能合约（产品没有，法律红线）
- ❌ 承诺"稳赚""每天 X 美元""保证回本"

**所有增长动作必须是创始人本人用自己的账号、自己的 PayPal、在自己的真实产品上执行。**

## 七、执行摘要（一页纸）

| 问题 | 答案 |
|---|---|
| 当前唯一瓶颈是什么？ | 流量 T = 0。数学上 ∂R/∂C = ∂R/∂A = 0，只有 T 能解锁收入 |
| 先打谁？ | 画像 A（隐私洁癖的第二大脑用户），其次 C（效率型重度用户） |
| 第一个渠道？ | Show HN（信任度 5、成本 5），3 天后 Product Hunt |
| 30 天目标？ | 拿到 ≥5 条真实付费意愿原话；争取 ≥1 笔真实付款（目标非承诺） |
| 7 天实验？ | 单一社区求 5 位试用者，问 3 个固定问题，只看真实付款 |
| 什么算成功？ | 即使 0 收入，只要测出真实需求信号，就把下一约束找到了 |
| 什么绝对不做？ | 刷量、群发、买号、冒充、区块链宣传、收入保证 |

> **核心结论：技术闭环已完成，收入的零因子只剩"被发现"。先用 7 天实验验证谁愿意付，再用 30 天把 0 变成 1；顺序不可颠倒，数字不可编造。**
